# caso-01

Habit tracker built as a study project: Clean Architecture per feature, Vite + React Router, Tailwind, shadcn/ui, Zod.

```bash
pnpm install
pnpm dev      # dev server
pnpm check    # format, lint, typecheck, test, build (same as CI)
```

Architecture and conventions: `CLAUDE.md`, `.claude/rules/`, `docs/design.md`.
